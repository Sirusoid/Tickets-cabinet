# Объем продукта (Product Scope)

## Основные функции
- **Админ-панель:** Управление билетами, клиентами, сеансами и настройками системы.
- **Кассовая система:** Регистрация продаж, выбор мест в зале, резервирование и расчет скидок.
- **Онлайн-виджеты:** 
    - Афиша (интеграция с Tilda).
    - Выбор мест и публичная покупка билетов через iframe.
- **QR-сканеры:** Нативные приложения для Android и iOS для быстрой проверки билетов на входе.
- **Платежи:** Интеграция с BCC gateway (онлайн-оплата, уведомления о возвратах).
- **Генерация PDF:** Автоматическое создание билетов, отчетов продаж и мануалов кассира.

## Целевая аудитория
Администраторы театра, кассиры, зрители (через публичные виджеты).
