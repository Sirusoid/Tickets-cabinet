# Технологический стек (Tech Stack)

## Backend
- **Язык:** PHP 8.5
- **База данных:** MariaDB / MySQL
- **Драйвер БД:** PDO
- **Генерация PDF:** Dompdf
- **Работа с Excel:** PhpSpreadsheet
- **QR-коды:** BaconQrCode, Endroid QR Code

## Frontend / UI
- **Стили:** CSS (включая кастомные стили для виджетов)
- **Интерактивность:** JavaScript (AJAX, анимации интерфейса)
- **Мобильные платформы:** Android (Kotlin + CameraX + ML Kit), iOS (SwiftUI).

## Инфраструктура
- **Веб-сервер:** Apache / Nginx (локально PHP Built-in Server)
- **Git:** Система контроля версий для отслеживания изменений.
