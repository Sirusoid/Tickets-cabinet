# Проект: Tickets cabinet (Театр «Жас сахна»)

## Общее описание
Система управления билетами и кассовыми операциями для Алматинского театра «Жас сахна» им. Б. Омарова. Система включает в себя админ-панель, онлайн-виджеты, мобильные приложения для сканирования QR-кодов и систему онлайн-оплаты через BCC.

## Текущий статус
Инициализирован проект, проведено первичное исследование структуры файлов и базы данных. Настроена локальная среда разработки.
