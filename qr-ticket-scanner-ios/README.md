# QR Ticket Scanner for iPhone

Нативное iOS-приложение для контролёров театра.

## Технологии

- Swift
- SwiftUI
- AVFoundation
- URLSession

## Сборка на Mac

1. Откройте `TicketScanner.xcodeproj` в Xcode на macOS.
2. В настройках target выберите свою Apple Developer Team.
3. Проверьте Bundle Identifier: `kz.zhassahna.ticketscanner.ios`.
4. Подключите iPhone и запустите приложение для теста.
5. Для App Store выберите `Product > Archive`, затем `Distribute App > App Store Connect`.

Для публикации потребуются Apple Developer Account, сертификаты подписи,
иконки приложения, скриншоты и ссылка на политику конфиденциальности.
